# Voices

Put the voice samples here: one audio file per voice (wav, m4a, mp3, flac, ogg). The file name is
the voice name shown in the web interface. Without `--ref`, the command line uses the first file
by name.

A good sample:

- 5-15 s of one person speaking naturally, no music, no other voices. Only the first 10 s are used.
- Recorded with the microphone and room you want to hear: both end up in the cloned voice.
- Silence at the start and at the end is trimmed automatically.

Only clone voices you have permission to use. The files in this folder stay on your computer and
are ignored by git.
